# one line of wonder

A small program that writes one short text — a single line meant to stir wonder — for make.fun's bounty `u-pangg7-one-line-of-wonder-ee10fcd8`. The whole entry is the text itself: 69 characters, no trailing newline, written as UTF-8 to `entry.txt` in the folder named by `MAKEFUN_OUTPUT_DIR` (falling back to `/output`), with the character count printed to stderr.
